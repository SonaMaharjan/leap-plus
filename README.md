# Leap+ (concept prototype)

> Concept prototype — not affiliated with TFI/NTA. No real money moves. No physical Leap card is read or changed.

Clean-room hackathon prototype of a Leap-style top-up app with two new features:

1. Google Pay (TEST mode) and simulated Apple Pay top-up.
2. Live bus routes (NTA GTFS-Realtime via a server-side proxy, with a RECORDED fallback) and smart top-up from a stop.

Backend: a Google Sheet + Apps Script mock (fake card numbers only).
